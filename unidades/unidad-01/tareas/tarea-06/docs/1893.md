### 📋 Diccionario Maestro de Variables (Módulo 1893)

#### 1. Grupo de Identificación y Llaves (Maestras)

_Estas variables son obligatorias para cualquier `merge` (cruce). Definen de forma única a cada productor y parcela._

| Variable               | Descripción                                                          |
| ---------------------- | -------------------------------------------------------------------- |
| `CCDD`, `CCPP`, `CCDI` | Códigos de ubicación geográfica (Departamento, Provincia, Distrito). |
| `NSEGM`                | Número del segmento censal (área de muestreo).                       |
| `ID_PROD`              | Identificador único del Productor Agropecuario.                      |
| `UA`                   | Número de la Unidad Agropecuaria.                                    |

#### 2. Grupo de Ubicación y Georreferenciación (Espacial)

_Vitales para tu análisis de pisos altitudinales. Permiten extraer la altitud en msnm mediante sistemas GIS._

| Variable   | Descripción                                              |
| ---------- | -------------------------------------------------------- |
| `LATITUD`  | Coordenada Y (Georreferencia del segmento).              |
| `LONGITUD` | Coordenada X (Georreferencia del segmento).              |
| `REGION`   | Clasificación geográfica oficial (Costa, Sierra, Selva). |

#### 3. Grupo de Caracterización y Filtros (Contexto)

_Te ayudan a validar si el dato es representativo y a filtrar el perfil del productor._

| Variable           | Descripción                                                                                        |
| ------------------ | -------------------------------------------------------------------------------------------------- |
| `FACTOR_PRODUCTOR` | **Crucial:** Factor de expansión para convertir datos de muestra en datos estadísticos nacionales. |
| `P104_SUP_ha`      | Superficie total de todas las parcelas (escala de la explotación).                                 |
| `P111`             | Condición jurídica (Propietario, Comunero, Arrendatario).                                          |
| `P141`             | Sistema de riego (identifica si hay tecnología hídrica).                                           |

#### 4. Grupo de Actividad Productiva (Uso de Tierra)

_Lo que define qué se está produciendo en la unidad._

| Variable      | Descripción                                                   |
| ------------- | ------------------------------------------------------------- |
| `P115_NOM`    | Nombre del cultivo instalado al momento de la entrevista.     |
| `P115_COD`    | Código del cultivo (estandariza el nombre para el análisis).  |
| `P117_SUP_ha` | Superficie específica sembrada para ese cultivo en hectáreas. |
| `P121`        | Sistema de riego utilizado específicamente en ese lote.       |
